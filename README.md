# Recenturesoft Corporate Website

A minimal, premium and responsive corporate website for Recenturesoft.

## Official Website

https://www.recenturesoft.com/

## Technology Stack

- Next.js App Router
- React
- TypeScript
- CSS Modules or global CSS
- Vercel deployment

## Project Type

Frontend-only website.

No backend, database, authentication or API integration is required.

## Pages

1. Home
2. About Us
3. Software Development
4. AI Automation
5. Contact Us

## Design

- Dark blue to light blue color palette
- Professional typography
- Minimal corporate layout
- Fully responsive design
- Lightweight animations
- Performance-focused implementation

## Setup

Install a supported Node.js LTS release.

Create a Next.js project with TypeScript and App Router.

Choose npm, pnpm or yarn and use the same package manager consistently.

Install dependencies using the generated package.json and its corresponding lockfile.

## Development

Run the development server using the selected package manager's standard Next.js development command.

Before deployment, run lint checks and a production build.

## Content and Images

Use verified information from the official company website.

Record image sources and licensing information in ASSET_SOURCES.md.

## Performance

Measure actual mobile and desktop performance using Lighthouse.

A specific 1ms load time cannot be guaranteed.

## Deployment

The completed frontend should be deployable on Vercel.
